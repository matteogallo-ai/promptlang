# Service level objectives

PromptLang runs no service: the compiler is local and deterministic, and its
speed is in `docs/benchmarks.md`. The objectives below are for the one part that
depends on a provider, a call of the AI linter (`analyze --ai`, one call per
prompt, `claude-haiku-5-5`, `max_tokens` 4096, no retries). The targets live in
`scripts/eval-report.ts` (`SLO`), which also checks them against the latest
linter eval record.

- **p95 latency per call ≤ 20 s.** A linter answer is up to 4096 output tokens;
  the client's timeout is 60 s, so 20 s leaves a call that is slow but useful
  well clear of a call that is abandoned. Measured around each provider call,
  from the machine that ran the eval, successful calls only.
- **Calls without a verdict ≤ 2%.** A request failure or an answer that is not
  the expected JSON leaves a prompt unlinted; above 2%, a run over a few dozen
  prompts usually misses one, and the result can no longer be read as complete.
- **Mean cost per call ≤ $0.001.** Half of the worst case the estimate charges
  (4096 output tokens ≈ $0.0020 plus the input), which is what an answer of a
  normal length costs. No call can exceed its worst case: the approved estimate
  is a cap (`src/testing/budget.ts`).
