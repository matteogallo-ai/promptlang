# PromptLang 2.0.0

The first release of `@promptlang/core` on npm. It follows an external audit
(2026-11-02) which found that the README's two headline features did not exist and
that the package could not be installed. Both are now true. Every capability the
README advertises in its comparison table and feature list has a passing test
listed in `docs/CLAIMS.md`.

```bash
npm install @promptlang/core
```

## What is new

- **Native tests.** `promptlang test` runs a file's `test` blocks against the
  generated TypeScript. It replays `mock:` responses by default, with no network.
  With `--live` it calls Anthropic after a cost estimate and your approval.
  Assertions: equality, `contains`, `matches`, `schema`. Exit codes:
  - `1` a test failed;
  - `3` a call failed and left a test without a verdict, labelled configuration
    error or provider failure.
- **SemVer for prompts.**
  - `@version` must be SemVer 2.0.0.
  - `import … requires "^1.0.0"` fails with `VersionMismatchError`.
  - `promptlang semver-check` compares each prompt's interface (parameters, output
    type, model) with a Git base, and fails when `@version` did not move enough.
  - `bun run demo` plays the whole scenario.
- **Cross-provider fallback.** `RoutingClient` takes `{ client, modelMap }`, so an
  Anthropic → OpenAI fallback sends OpenAI its own model name. `Retry-After` is
  honoured on 429.
- **Cost control.** `analyze --ai` and `test --live` print an estimate and ask
  before any paid call; `--yes` approves. Neither retries a call.
- **Python runtime.** Empty keys refused, HTTP errors raise typed
  `PromptClientError` subclasses, malformed responses raise `InvalidResponseError`.
  It does not retry; timeouts and connection failures raise `httpx` exceptions.
- **Anthropic API 2026-10-21.** Both runtimes send this version and never send
  `temperature`. The AI linter runs on `claude-haiku-5-5`.

## Breaking changes

See `docs/migration-guide.md` (1.2.0 → 2.0.0). In short:
- the package name and `exports` changed;
- generated code imports `@promptlang/core/runtime` (recompile);
- `@version` must be SemVer;
- `compile --target` accepts only `typescript` or `python`;
- `@temperature` is not sent to Anthropic.

## Known limitations

- `eval` blocks are parsed but not executed.
- The AI linter has one committed live run (`runs/live/`, 5/5 calls returned). One
  sample does not measure the quality of its findings.
- The `promptlang` CLI needs Bun ≥ 1.2.20. The library and the runtime run on
  Node ≥ 20.
- `@promptlang/yaml-parser` 1.0.0 on npm ships TypeScript sources, which Node
  cannot import. `@promptlang/core` bundles its own copy and does not depend on it.

## Verifying the package

The tarball is published from `.github/workflows/release.yml` with npm provenance:
the package's npmjs.com page links each version to the workflow run that built it
(<https://docs.npmjs.com/generating-provenance-statements>).
