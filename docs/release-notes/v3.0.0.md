# PromptLang 3.0.0

This release fixes the 23 findings of a neutral audit (2026-11-03,
`docs/audit/`). Several fixes refuse what 2.x accepted silently: an answer of
the wrong type, a folder whose outputs overwrite each other, a name the target
language cannot hold. That makes it a major version. Recompile every `.prompt`
file and upgrade `@promptlang/core` in the same step: code generated by 3.0.0
needs the 3.0.0 runtime.

```bash
npm install @promptlang/core@3
```

## What changes

- **Answers are checked against the declared type.** Generated TypeScript and
  Python check every answer and raise `InvalidOutputError` when it does not
  conform. 2.x cast a struct answer to its type unchecked: a string amount and an
  extra field came back typed. Both languages are run on the same answers in the
  tests and must agree.
- **Incomplete answers are errors.** An answer cut at `max_tokens`, refused,
  stopped early or empty raises `IncompleteResponseError` with its `reason` and
  billed `usage`. It is not retried, and `RoutingClient` does not fall back on it.
- **`compile` refuses what it cannot compile correctly.** Two sources writing one
  file or exporting one name, and names the target cannot hold, are errors with
  a position. `compile` writes nothing then. Python modules get importable names
  (`sentiment.v2.prompt` → `sentiment_v2.py`). The output carries no timestamp,
  so the same source gives the same bytes.
- **Fallback only when a provider could not serve.** `RoutingClient` sends the
  request on after an outage, a rate limit, a timeout, a network failure, a 404
  or a malformed body. A 400 or a bug is thrown, so the user's data is not sent
  to a second provider for nothing. A 404 is `NotFoundError` in every client.
- **Struct parameters are sent as JSON**, the same bytes from TypeScript and
  Python, instead of `[object Object]` or a dict repr.
- **The spending cap holds on long prompts.** Each call is priced on the rate
  card its prompt length selects (Claude Haiku 5.5 bills five times more above
  100K tokens).
- **`prompt-injection-risk` judges each placeholder by its own delimiters**, in
  every role, and no longer flags numbers, booleans or enums.
- **`semver-check` treats declared type names as interface**: renaming an
  exported type is a major change.
- **`OpenAIClient` sends `max_completion_tokens`**, which GPT-5 and the o-series
  require.
- `promptlang --version`.

## Breaking changes

See `docs/migration-guide.md` (2.x → 3.0.0). In short:
- answers outside the declared type raise `InvalidOutputError`, and a `mock:`
  answer outside it fails its test;
- incomplete answers raise `IncompleteResponseError`;
- `compile` refuses colliding outputs and more names, and renames Python modules;
- a 404 raises `NotFoundError`; `RoutingClient` no longer falls back on a 400;
- generated TypeScript imports `parseOutput` from the runtime as a value;
- `analyze --strict` can fail on a file that passed.

## Known limitations

- `eval` blocks are parsed but not executed.
- The AI linter's precision is about 20%, against 12.5% for a baseline that
  reports every category; its labels are set by construction, and their human
  check (`evals/linter/human-review/`) has no answers recorded.
- Mutation testing covers the lexer, the parser and `src/semver/` only.
- Triple-quoted strings are sent as written, indentation included.
- A delimiter is not escaping: an input that contains the closing delimiter
  still closes it, which no static rule can see.
- The `promptlang` CLI needs Bun ≥ 1.2.20. The library and the runtime run on
  Node ≥ 20.

## Verifying the package

This version is published through npm trusted publishing: the workflow
authenticates with its OIDC token, no npm token is involved, and npm records
provenance linking the version to the workflow run that built it
(<https://docs.npmjs.com/trusted-publishers>).

The same tarball is attached to this release with its signed build provenance
(`promptlang-core-3.0.0.tgz.sigstore.json`):

```bash
gh attestation verify promptlang-core-3.0.0.tgz --repo matteogallo-ai/promptlang \
  --signer-workflow matteogallo-ai/promptlang/.github/workflows/release.yml
```
