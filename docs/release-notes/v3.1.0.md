# PromptLang 3.1.0

A minor release. Code generated by 3.1.0 rewrites a value inserted between
delimiters so that it cannot close or reopen them. Recompile your `.prompt` files
and upgrade `@promptlang/core` in the same step: generated TypeScript imports
`neutralizeDelimiters` from the 3.1.0 runtime when a file needs it.

```bash
npm install @promptlang/core@3.1.0
```

## Security: delimited values

Before 3.1.0, a ticket containing `</ticket>` closed the `<ticket>` tag around
it, and what followed read as the prompt's own text. The `prompt-injection-risk`
rule could not see it, since the value exists only at run time. Generated
TypeScript and Python now rewrite the value, byte for byte the same in both
languages, with the pairs the rule recognises around its placeholder:

- `<name>`…`</name>`, and `<BEGIN>`/`<END>`: a `<` that starts `<name` or
  `</name`, in any ASCII case, with spaces, tabs or line breaks around the `/`,
  becomes `&lt;`. `<tickets>` is left alone.
- `[[`…`]]`: `[[` becomes `[ [`, `]]` becomes `] ]`.
- A code fence: a run of three or more backticks gets a space between each.
- `---` lines: a line of three or more dashes gets a space between each dash.

A placeholder outside any delimiter is inserted as before, and the rule still
warns about it. How well a model respects delimiters is not measured.

## Other changes

- The CLI names why a file could not be read (`ENOENT`, `EACCES`, `EISDIR`).
- `bun run mutation` works from a fresh clone; CI runs it weekly, and a dry run
  on every pull request.
- Tests that run generated Python skip, with the reason, below Python 3.11.
- CI and releases use the Bun in `.bun-version`; TypeScript is pinned.
- The README fits on about one page; the reference is in `docs/`.

See `CHANGELOG.md` for the full list.

## Verifying the package

Published through npm trusted publishing (OIDC, no npm token), with npm
provenance. The same tarball is attached to this release with its signed build
provenance (`promptlang-core-3.1.0.tgz.sigstore.json`):

```bash
gh attestation verify promptlang-core-3.1.0.tgz --repo matteogallo-ai/promptlang \
  --signer-workflow matteogallo-ai/promptlang/.github/workflows/release.yml
```
