# PromptLang 3.0.1

A patch release. The library, the CLI and the code it generates are the same as
in 3.0.0; only the documentation that ships with the package changes.

```bash
npm install @promptlang/core@3.0.1
```

## Security

The README published with 3.0.0 (the npm page and the tarball) ran the CLI as
`npx` followed by the unscoped name `promptlang`. Without `@promptlang/core`
installed in the project, that command downloads and runs the unscoped
`promptlang` package, which belongs to a third party. The README now runs
`npx @promptlang/core`. `scripts/check-unscoped-cli.ts`, run as a test in
`bun test`, fails when a tracked file runs or installs the unscoped package.

If you ran the unscoped command from the 3.0.0 README in a directory without
`@promptlang/core`, you ran that third-party package.

## Other changes

- The README names `0.0.0-stage`, the only version on npm before 2.0.0: an empty
  placeholder, not a release.
- The npm keywords include `python`.
- The results of the human review of the AI linter's findings and of its eval
  labels are in `evals/linter/` (see `CHANGELOG.md`).

## Verifying the package

This version is published through npm trusted publishing (OIDC, no npm token),
with npm provenance. The same tarball is attached to this release with its signed
build provenance (`promptlang-core-3.0.1.tgz.sigstore.json`):

```bash
gh attestation verify promptlang-core-3.0.1.tgz --repo matteogallo-ai/promptlang \
  --signer-workflow matteogallo-ai/promptlang/.github/workflows/release.yml
```
